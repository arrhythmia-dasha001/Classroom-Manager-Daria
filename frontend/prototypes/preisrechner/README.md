# Preisrechner

Kleine Bibliothek mit Preis-Funktionen für einen Online-Shop (Küstenbyte GmbH).

- `brutto(netto, satz)` – Bruttopreis berechnen
- `rabatt(preis, prozent)` – Rabatt abziehen
- `runden(betrag)` – auf Cent runden
- `formatEuro(betrag)` – Betrag als Text, z. B. „15,50 €“

Doku erzeugen: `npm install`, dann `npm run docs` (Ergebnis in `docs/index.html`).
